I build and explore **practical AI systems**: from model post-training and GPU-conscious optimization to evidence-grounded agents and reproducible evaluation.

What interests me most is the gap between an impressive demo and a system that people can actually inspect, test, and rely on.

## Selected work

| Project | What it explores | Focus |
| :--- | :--- | :--- |
| **[Horizon Agent](https://github.com/KaanDRoid/horizon-agent)** | An evidence-first multi-agent investigation demo for renewable assets, using **synthetic data** and inspectable traces. | LangGraph · RAG · local inference |
| **[GRPO Training Lab](https://github.com/KaanDRoid/grpo-training-lab)** | Single-GPU LLM post-training with LoRA, resumable checkpoints, vLLM rollouts, and a Triton selected-logprob kernel. | GRPO · PyTorch · Triton |
| **[Evals & Judge Calibration](https://github.com/KaanDRoid/evals-judge-calibration)** | Local, auditable agent evaluation with executable graders, judge calibration, blinded annotation, and repeated-run analysis. | LLM evaluation · reliability · statistics |

## What I focus on

- **Post-training and optimization** — fine-tuning workflows, GPU memory constraints, and efficient training experiments.
- **Agent engineering** — tool use, retrieval, evidence provenance, and inspectable execution paths.
- **Evaluation and reliability** — measurable behavior, calibrated judging, repeatable tests, and failure analysis.
- **Production-minded AI** — thinking about latency, cost, observability, and the trade-offs behind dependable systems.

## How I like to build

**Evidence over claims.** Reproducible experiments, explicit limitations, readable code, and documentation that makes a project easier to verify.
